Detailed Description

Program argument description.

A full argument description is declared by ([] denotes, that the setting is optional): 

 {
     <long-option>, [<short-option>],
     <brief>,
     [<argument-type>=argument::none],
     [<value-type>=variant::none],
     [<default>],
     [<callback>]
 }

The fields in detail:

The long-option is always required, and, is also used as key in the parsed arguments (see vidre::arg::parser::parsed() ). Program arguments use "--<long-option>".

The short-option is a single, optional character. Program arguments use '-<short-option>', for example "-h" for displaying help.

The brief description, generally required, appears in the help text.

For the argument-type, see vidre::arg::argument::type, the default is none.

If applicable, either the value-type or the default value can be set (see vidre::arg::variant).

In addition, a callback function can be assigned, which gets called immediately after processing the option.

The full constructor is: 

 {"<long-option>",<short-option>,"<brief>",<argument-type>,<value-type>,<default>,<callback>}

The following constructors are supported: 

 {"<long-option>","<brief>"}
 {"<long-option>",<short-option>,"<brief>"}

 {"<long-option>","<brief>",argument::required,[<value-type>=variant::cstring]}
 {"<long-option>",<short-option>,"<brief>",argument::required,[<value-type>=variant::cstring]}

 {"<long-option>","<brief>",argument::optional,<default>}
 {"<long-option>",<short-option>,"<brief>",argument::optional,<default>}

 {"<long-option>","<brief>",argument::positional,[<value-type>=variant::cstring]}

Alternatives for positional arguments: 

 {"<long-option>","<brief>",argument::postional,[<value-type>=variant::cstring]}

is the same as 

 option::positional{"<long-option>","<brief>",[<value-type>=variant::cstring]}
