Detailed Description

General logging.

The general log interface used within the framework follows the convention:

log::LEVEL() << "message output" << log::endl;
vidre::log::endl
static constexpr message_type endl
End-of-line.
Definition log.hh:236

where LEVEL may be any of the existing log levels and may be used as if std::clog would be used directly.

Special conditions apply to the following levels:

  • log::fatal terminates the program when the object is destructed.
  • log::debug is only supported (i.e. functional) when initially compiled without NDEBUG.
  • log::trace is only available when explicitly compiled with DEBUG.
