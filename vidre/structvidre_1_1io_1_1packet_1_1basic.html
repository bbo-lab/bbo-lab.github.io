Detailed Description

This reflects the basic type of a packet (TLV encoded), which is used for dispatching to the appropriate handler. The actual content of the packet is determined by the major and minor types, and may be further specified by the stream ID (e.g., for multiplexed streams).

Type for shared pointer to basic packet.

Packets, due to life-time considerations, are usually managed via shared pointers, especially when they are passed around different components or threads. This type alias simplifies the creation and management of such shared pointers.

Create a shared pointer to a static packet.

This method creates a shared pointer to a packet that is statically allocated, meaning it does not manage the lifetime of the packet. The provided deleter does nothing, ensuring that the static packet is not deleted when the shared pointer goes out of scope.
