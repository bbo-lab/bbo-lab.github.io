Detailed Description

vidre/io/packet.hh

Packet-based I/O is designed for handling variable-sized data units, such as video frames or audio samples, which may not fit well into a stream-based model. It provides a structured way to read and write packets of data, each with its own header and payload. This allows for more efficient processing and better support for multiplexed data streams. In addition, VidRe uses the format for storing data on disk, as well as for inter-process or network communication.
