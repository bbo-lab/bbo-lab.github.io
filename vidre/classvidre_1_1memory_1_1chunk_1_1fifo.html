Detailed Description

template<size_type N>
class vidre::memory::chunk::fifo< N >
Template Parameters
NRing size. If zero (default), the ring is dynamically allocated, otherwise (requiring N being a power of 2) it is statically allocated.

This class is designed to manage a ring of pointers to data chunks (e.g. video frames) in a FIFO manner, where a "producer" queues pointers to new data chunks, while the output is consumed by a "consumer" in the same order.
