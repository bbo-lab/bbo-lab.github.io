Detailed Description

This class provides a simple mechanism for threads to signal events to each other using the Linux eventfd mechanism (emulated on other platforms). It allows one thread (the "producer") to notify another thread (the "consumer") about the occurrence of an event. The consumer will receive the notification count, which indicates how many times the event was signaled since the last wait.

Note
This class is designed to be used in a single-producer, single-consumer scenario. It does not support multiple producers or consumers, and it does not provide any synchronization mechanisms for concurrent access.

Also, the object of this class should be shared between the producer and consumer threads (e.g. via a shared pointer).

result vidre::event::wait ( std::chrono::milliseconds timeout)
inlinenodiscard

Wait for the event to be notified, with a timeout.

Parameters
timeoutThe maximum time to wait for the event.
Exceptions

c exception::runtime with error::system information if the wait operation failed due to a system error.

Returns
result containing the status and the notification count.

Example:

bool running = true;
while (running) {
event::result res = ev.wait(std::chrono::milliseconds(100));
switch (res.status) {
case event::state::success:
// handle event, res.count contains the notification count
break;
case event::state::timed_out:
// handle timeout
continue;
case event::state::terminated:
running = false; // handle termination
continue;
default:
// never reached (exceptions are thrown otherwise)
break;
}
}
