struct vidre::video::frame::__attribute__ ( (packed) )
inline

Per-frame information.

This structure contains metadata associated with a video frame, such as timestamps, geometry, and pixel format. The actual pixel data of the frame is stored separately in the data member of the frame class.

The object is packed and, therefore, suitable to be stored in a file fileformat. Mind endianness, though.

< Frame number (if available).

< Timestamp from the camera (if available).

< Timestamp from the system clock (steady_clock).)

< Layout of the video frame (position and size).

< Pixel format of the video frame.
