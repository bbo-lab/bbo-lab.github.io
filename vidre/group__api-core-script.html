Detailed Description

libs/core/vidre/script.hh

VidRe provides scripting functionality through Lua (version 5.4 at the moment of writing). Its major purpose is to facilitate complex configuration scripts of devices, such as cameras, where, for example, setting or retrieving the frame rate involves setting several registers (note, that the USB3Vision standard implements this using XML files).
