Detailed Description

libs/core/vidre/exception.hh

There are many pro's and con's for using exceptions versus error return types—which we shall not repeat here. We should note, though, that the mantra that exceptions are generally slower is untenable.

Within VidRe, exceptions are used for transporting terse error reporting information, and, therefore, should not be used in fast code paths (use std::optional and std::expected there).
