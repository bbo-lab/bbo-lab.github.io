Detailed Description

Plugins that produce or consume data require some form of communication with the rest of the system, which can be implemented in different ways. These communication "endpoints" are categorized by their technical implementation and require specific configuration parameters, described in FIXME.

With few exceptions, plugins will only use local IPC. There, in general, Unix domain sockets are preferred. However, to support remote communication, especially when the daemon runs on a headless system, TCP/IP sockets can also be used for remote control. We recommend, though, using SSH tunnels for secure communication in that case.
