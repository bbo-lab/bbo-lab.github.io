vidre::detail::io::buffer Struct Reference
C++-API » Core library » In-/output » Implementation details

#include <vidre/io/types.hh>

Detailed Description

This simple buffer is mainly intended for use with sinks only, especially when using synchronous file writes. There, writing data not being a multiple of the underlying hardware's block size, can be orders of magnitude slower.

See also
io::file::sink
