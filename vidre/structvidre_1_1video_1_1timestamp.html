Detailed Description

Timestamp.

To avoid calculations (esp. divisions) on the critical path of frame acquisition, timestamps are represented as a value and a resolution (in Hz). The actual timestamp in seconds can be calculated as value / resolution. The default resolution is 1 ns (1 GHz), which allows for high-precision timestamps without needing to use floating-point values.

See also
std::chrono::duration for a more flexible representation of time intervals, if needed.
