Detailed Description

Static error message.

Some implementations passing error messages (for example std::error_code::message()) create temporary strings which are not usable with exceptions. This class provides a mechanism with static storage for passing such messages.

Usage:

const char *system_error::what() const noexcept {
static thread_local static_error_message msg;
msg = ec_.message();
return msg;
}
