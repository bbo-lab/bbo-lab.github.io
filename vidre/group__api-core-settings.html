Detailed Description

libs/core/vidre/settings.hh

Configuration files are, as also stated elsewhere, implemented using Lua (see Scripting). The advantage of using Lua as a configuration language is, that it also allows to implement complex functions, such as is required for abstracting camera interfaces, where, for example setting the frame rate or exposure time, would require, first to do calculations and, second, update multiple registers at once.
