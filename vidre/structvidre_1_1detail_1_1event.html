int vidre::detail::event::notify ( value_type count = 1)
inline

Notify the event, i.e.

wake up the consumer.

Parameters
countThe number of notifications to send (default: 1).
Returns
Status indicating whether the notification was successful (i.e. count notifications were sent) or not (i.e. the counter is full).
Exceptions

c exception::runtime with error::system information if the notification failed due to a system error.

Note
This call fails if max_count would overflow.
