Detailed Description

This class, eventually only used by the sink, provides a simple mechanism for signaling when a component is "busy" (e.g., processing data) and when it is ready to accept new data.

The consumer (sink) can call busy::clear() to signal that it is ready for new data, and the producer (source) can call busy::wait() to wait until the consumer is ready. This can be useful for flow control, especially when dealing with components that have variable processing times or when implementing backpressure mechanisms.

Note, however, that producers (especially isochronous ones) may ignore the busy state and continue producing data, which may lead to data loss if the consumer cannot keep up (which is, in fact, intended behavior).
