#include <vidre/io/types.hh>

Detailed Description

This struct encapsulates the result of low-level IO operations, including whether an error occurred and how many bytes were processed.

Typical usage:

io::result res;
res += sink.write(bufA, countA);
res += sink.write(bufB, countB);
return res;

Add another result to this result.

Parameters
otherThe result to add.
Returns
Reference to this result.

This operator allows for easy accumulation of results, such as when performing multiple read/write operations in a loop. If any operation fails (i.e., has an error), the resulting error flag will be set to true (accumulated), and the count will reflect the total number of bytes successfully processed up to that point.
