Detailed Description

libs/core/vidre/log.hh

VidRe provides a program-flow and message logging interface that supports several severity levels (including nested tracing):

  • log::fatal (which also terminates the program),
  • log::alert,
  • log::critical,
  • log::error,
  • log::warning,
  • log::notice,
  • log::status,
  • log::info,
  • log::debug, and,
  • log::trace,

(the latter are compile-time enabled only if NDEBUG is not defined and DEBUG is defined, respectively, at compile-time). These classes my be used for single or block-wise output, such as

log::notice() << "A notice.\nMore information for this notice.\n";

vs.

log::notice notice;
notice << "A notice.\n";
notice << "More information for this notice.\n";
Note
VidRe in general only uses a single newline character ('\n') to emit or determine an end-of-line (see also log::endl).

The logging interface also allows to stream its output to different locations (see log::io::stream) with styling (see log::io::style) where each stream may have it's own log threshold (see log::threshold).

By default, all logging is sent to std::clog (id 0).

Example (see examples/core/log.cc):

#include <vidre/log.hh>
using namespace vidre;
void simple_logging() {
log::warning() << "A warning...\n";
log::notice() << "...and a notice" << log::endl;
}
void block_wise() {
log::notice notice;
notice << "a = " << 1 << log::endl;
notice << "b = " << 2 << log::endl;
}
void level3() {
log::trace tr;
tr << "entering level 3\n";
tr << "leaving level 3\n";
}
void level2() {
log::trace tr;
tr << "entering level 2\n";
level3();
tr << "leaving level 2\n";
}
void level1() {
log::trace tr;
tr << "entering level 1\n";
level2();
tr << "leaving level 1\n";
}
void tracing() {
#if defined(DEBUG)
{
log::io::file trf("/tmp/trace.log", log::level::trace);
// set default streamer threshold to "trace"
log::io::stream::threshold(0, log::level::trace);
// set wildcard pattern for what to trace
log::trace::pattern("*/core/*");
// trace...
log::debug() << "starting to trace\n";
log::trace tr;
tr << "tracing 3 levels\n";
level1();
}
log::notice() << "done tracing\n";
#endif
}
int main(int argc, const char **argv) {
#if not defined(DEBUG)
// log::fatal() does not return but instead terminates the program
log::fatal() << "This example should be executed with full debugging enabled.\nExiting...\n\n";
#endif
simple_logging();
block_wise();
tracing();
return 0;
}
