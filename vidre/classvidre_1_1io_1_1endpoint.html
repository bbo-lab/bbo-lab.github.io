enum vidre::io::endpoint::cap : uint32_t

Capabilitie list.

Enumerator
none 
stream 

Stream mode (e.g., for files or network sockets).

packet 

Packet mode (e.g., for video frames or audio samples).

any 

Any mode (default).

loop 

Endpoint is thread-based (e.g., for live video capture).

The endpoint produces data in a seperate thread, and data availability is signaled via events.

ondemand 

Endpoint is on-demand (e.g., for memory buffers).

The endpoint produces data on demand, i.e., when the consumer requests it.
