◆ file() [6/6]

vidre::io::file::file ( FILE * f)
inlinenoexcept

Open a file from a C FILE pointer.

Parameters
fThe C FILE pointer.

This constructor is intended for use with stdin, stdout, and stderr, but can be used with any valid FILE pointer.

Note
The file will be duplicated, so the caller retains ownership of the FILE pointer and is responsible for closing it. The returned file object will have its own file descriptor that is independent of the original FILE pointer.
