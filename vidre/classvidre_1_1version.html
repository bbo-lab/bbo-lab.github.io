◆ version() [4/4]

vidre::version::version ( std::string_view str)

String constructor.

The string should be in the format "MAJOR.MINOR.PATCH", where MINOR and PATCH are optional. If a component is missing, it will be set to undefined.

If MINOR or PATCH are omitted, the version string must not contain any additional characters.

Punctiuation and suffixes (e.g., "1.2.3-alpha") are allowed after the PATCH component, but will be ignored.

◆ operator<=>()

std::strong_ordering vidre::version::operator<=> ( const version & other) const
inlineconstexprnoexcept

Three-way comparison.

The comparison is performed component-wise, starting with the major version, then minor, and finally patch. If a component is undefined in either version, it is considered less than any defined value for that component. If both components are undefined, they are considered equal.

Note
If one of the versions is not valid (ie. the major version is undefined), the result is unspecified.
