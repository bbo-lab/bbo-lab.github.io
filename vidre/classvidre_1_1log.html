Detailed Description

Message logging interface.

This provides an interface for program-flow and general message logging.

By default, log messages are emitted to std::clog but may also be recorded in a file or a temporary buffer (see log::stream for further information).

Typical usage (see log::level):

log::warning() << "A warning.";

Log levels.

The log levels are represented as individual classes, so instead of using

log(log::level::warning) << "A warning.";

log()=default

users must use

which provide additional functionality (see esp. log::fatal and log::trace .
