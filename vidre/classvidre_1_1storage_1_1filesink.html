◆ mode_type

enum vidre::storage::filesink::mode_type : uint32_t

Open mode.

Enumerator
none 
truncate 

Truncate file if it exists, otherwise create or append to the file.

synchronous 

Transfer data synchronously to the underlying hardware.

Using this option includes block-wise buffering to reduce workload on the underlying hardware.

unbuffered 

Disable automatic buffering.
